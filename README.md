# Учёт — клиенты, заказы, оплаты, расходы

Android-приложение для учёта небольшого бизнеса (грузы / Китай). Валюта — доллары, всё хранится на телефоне (SQLite), интернет не нужен.

## Что умеет

- **Клиенты** — список с долгом/авансом, поиск, карточка клиента с историей.
- **Заказы** — груз, вес (кг), количество, сумма, дата приёма и выполнения (ставятся автоматически). Долгое нажатие — отметить выполненным.
- **Оплаты** — «клиент дал $N». Привязка к заказу необязательна, сумма уменьшает общий долг клиента. Кнопка «Весь долг».
- **Расходы** — по категориям (груз, доставка Китай, машина…, можно свои).
- **Главная** — за месяц: пришло / потрачено / прибыль, общий долг клиентов.
- **Отчёты** — каждый месяц отдельно, новый месяц начинается сам. Экспорт в Excel и PDF, Excel за всё время.
- **Резервная копия** — файл базы через «Поделиться» (Telegram и т.п.) и восстановление из него.

## Логика расчётов

- Прибыль месяца = оплаты, полученные в этом месяце − расходы этого месяца.
- Долг клиента = все его заказы − все его оплаты (за всё время). Минус = аванс.

## Сборка

APK собирается GitHub Actions при каждом push в `main` (`.github/workflows/build.yml`):
готовый файл — в **Releases** (`build-N`) и в артефактах запуска.

Папка `android/` генерируется в CI командой `flutter create`. Для локальной разработки:

```bash
flutter create . --platforms=android --org com.akbar --project-name cargo_uchet
flutter run
```

`ci/debug.keystore` — постоянный ключ подписи, чтобы новые сборки ставились поверх старых без потери данных. Не удаляйте его. Если репозиторий станет публичным — перенесите ключ в секреты.

## Структура

```
lib/
  main.dart                 навигация (5 вкладок)
  models.dart               модели, YearMonth, MonthSummary
  db.dart                   схема SQLite
  store.dart                хранилище (ChangeNotifier), расчёты балансов и итогов
  forms.dart                формы клиента / заказа / оплаты / расхода, выбор клиента
  format.dart               деньги и даты
  screens/                  экраны
  services/export_service.dart  Excel, PDF, резервная копия
```
