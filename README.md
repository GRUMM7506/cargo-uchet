# Учёт / Hisob-kitob — должники, заказы, залоги, расходы

Android-приложение для небольшой мастерской: клиент заказывает работу, мы записываем цену и залог,
принимаем оплаты и всегда видим, кто сколько должен. Валюта — доллары, всё хранится на телефоне.
Языки: русский и узбекский (латиница), переключение в настройках.

## Что умеет

- **Заказ** — клиент, фото работы, что за работа, цена, залог (сумма и дата), дата приёма,
  срок сдачи, отметка «выполнен», заметка. Просроченные заказы подсвечиваются.
- **Долг** — по каждому заказу (цена − залог − оплаты по заказу) и по клиенту в целом.
- **Оплаты** — «клиент дал $N», можно привязать к заказу. Кнопки «Весь долг» и «Остаток по заказу».
- **Клиенты** — фото/аватар, долг или переплата, история заказов и оплат.
- **Расходы** — по категориям (Китай, груз, машина, материалы, аренда…, можно свои).
- **Главная** — прибыль месяца, долг клиентов, топ должников, движение денег по дням.
- **Отчёты** — график за 6 месяцев, отчёт по месяцу, экспорт в Excel и PDF на выбранном языке.
- **Настройки** — язык, тема (авто / светлая / тёмная), цвет, какие поля заказа показывать,
  резервная копия (zip с базой и фото) и восстановление.

## Логика расчётов

- Приход месяца = залоги, полученные в этом месяце + оплаты этого месяца.
- Прибыль месяца = приход − расходы месяца.
- Долг клиента = цены всех его заказов − залоги − оплаты (за всё время). Минус = переплата.

## Сборка

APK собирается GitHub Actions при каждом push в `main` (`.github/workflows/build.yml`):
готовый файл — в **Releases** (`build-N`). Лог сборки CI пишет в ветку `ci-logs`.

Папка `android/` генерируется в CI командой `flutter create`. Для локальной разработки:

```bash
flutter create . --platforms=android --org com.akbar --project-name cargo_uchet
flutter run
```

`ci/debug.keystore` — постоянный ключ подписи, чтобы новые сборки ставились поверх старых без потери данных.
Не удаляйте его. Если репозиторий станет публичным — перенесите ключ в секреты.

## Структура

```
lib/
  main.dart                     навигация, тема, язык
  l10n.dart                     все тексты: русский и узбекский
  theme.dart                    светлая/тёмная тема, смысловые цвета
  settings.dart                 настройки (в той же SQLite → попадают в копию)
  models.dart                   модели, YearMonth, MonthSummary
  db.dart                       схема SQLite и миграции
  store.dart                    хранилище, расчёт долгов и итогов
  forms.dart                    формы клиента / заказа / оплаты / расхода
  screens/                      экраны (главная, клиенты, заказы, карточка заказа, расходы, отчёты, настройки)
  services/photos.dart          фото клиентов и заказов
  services/export_service.dart  Excel, PDF, резервная копия
```
